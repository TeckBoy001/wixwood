# WixWood Project Bundle

Start with **ANTIGRAVITY_INSTRUCTIONS.md**.

```
WixWood_Project_Bundle/
├── ANTIGRAVITY_INSTRUCTIONS.md     <- full build brief (read first)
├── PROMPT_TO_PASTE.txt             <- short prompt to give Antigravity
├── 01_laravel_app/                 <- the app to build and ship (not yet run)
├── 02_static_site/index.html       <- finished front-end, single file
├── 03_node_reference_backend/      <- tested reference backend (behaviour spec)
├── 04_design_docs/                 <- brochure, design preview, order-flow PDF
├── 05_real_photos/                 <- real WixWood photos from the owner
└── 06_original_briefs/             <- the owner's original prompts
```
